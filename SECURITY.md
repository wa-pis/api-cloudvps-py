# Security policy

## Supported versions

Security fixes are provided for the latest published 0.2.x release. Version
0.1.7 and earlier are unsupported.

## Reporting

Report vulnerabilities privately through GitHub's **Security → Report a
vulnerability** flow for this repository. If private vulnerability reporting is
unavailable, contact the maintainer at `onepis2word@gmail.com` before opening a
public issue.

Never include a live REG.Cloud bearer token, PyPI credential, recovery code, or
complete Authorization header. Replace credentials with clearly fake values and
remove account identifiers unless they are essential to reproduce the issue.

The maintainer will acknowledge a report, assess affected versions, coordinate a
fix and disclosure, and revoke any exposed credential. REG.Cloud platform issues
that do not originate in this client should also be reported to REG.Cloud.
